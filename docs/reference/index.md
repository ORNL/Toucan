# Reference

This reference follows Toucan's current source interfaces:

- [JSON input](json-input/) covers material, RNG, domain, MPI, nucleation,
  substrate, and output settings.
- [Thermal sources](thermal-sources/) covers Stork file input, in-memory Condor
  execution, and the direct RDF contract for other thermal solvers.
- [CLI and Library API](api/) covers executable use and the callable C++ lifecycle.
- [Output](output/) describes generated fields and file naming.
